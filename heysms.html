Building the project for 50 M+ monthly messages

HeySMS needed a complete platform to support enterprise-grade delivery, while staying intuitive for day-to-day use. From account management to billing and support, the experience had to work seamlessly for teams operating across time zones and use cases.

Built for control, clarity, and scale

The architecture handles massive traffic while keeping the user flow clean and easy to navigate. Each interface was designed to simplify operations, not mask complexity, but organize it.

During website development, I structured and systematized the UI kit, establishing a consistent design system. All design tokens were documented in Figma, ensuring consistency across components, streamlining design workflows.

Authentication & account recovery flows

Designed comprehensive authentication flows, including login, email verification, and password reset. Each flow was carefully developed to ensure a seamless and intuitive user experience, with all possible states, validation scenarios, error messages, and success notifications thoroughly considered. The result is a consistent and reliable system that guides users smoothly through every step of the authentication process.

Section design & logic development

Designed key interface sections and collaborated with analysts to define the implementation logic for sender ID management and filtering.

Branding & media positioning

A distinctive visual style was developed for the brand’s media presence, built around green and a signature diagonal stripe. Each visual communicates the simplicity of sending SMS messages and managing them efficiently.
